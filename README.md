# React Native UI Lab 🚀

**A playground for creative interfaces, animations, and interactive experiments built with React Native.**

React Native UI Lab is an open-source collection of UI experiments. Each showcase explores a different interaction, visual effect, or animation technique, with code you can explore and adapt.

## ✨ Experiments

1. **[Glowing Lines](src/showcases/GlowingLines/index.tsx)** — Interactive glowing strings with physics-based motion.
2. **[Gradient Letter](src/showcases/GradientLetter/index.tsx)** — Layered 3D gradient letter with swipe interactions.

## 🚀 Getting Started

**Prerequisites:** Node.js 22.13.0 or newer, npm, and an Expo-compatible iOS or Android development environment.

Clone and install:

```bash
git clone https://github.com/Emin91/ReactNativeUILab.git
cd ReactNativeUILab
npm install
```

Start Expo:

```bash
npx expo start
```

Then follow the instructions in the Expo terminal to open the project on your device or simulator. Some native-library features may require a development build instead of Expo Go, depending on your environment.
